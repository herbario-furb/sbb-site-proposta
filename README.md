# Proposta de novo site – Sociedade Botânica do Brasil

Proposta de layout e reorganização do site [botanica.org.br](https://www.botanica.org.br), feita para discussão interna. **Não é o site oficial.**

## Como ver

Baixe o repositório (botão **Code › Download ZIP**) e abra `index.html` no navegador.

- `index.html` – página inicial redesenhada
- `mapa-do-site.html` – novo menu, com o conteúdo atual reorganizado em 7 grupos

## O que falta

Os itens entre colchetes são espaços reservados: logo oficial, imagens das exposições virtuais e dados do 77º Congresso Nacional de Botânica.

## Sobre as planilhas

As planilhas do Google Drive podem continuar sendo a fonte dos dados (congressos, diretorias, eleições). A proposta é que o site leia essas planilhas e mostre os dados em tabelas e cartões no padrão visual, em vez de exibir a planilha embutida.
